	其实流水灯不应该放在中断，而应该作为并行的任务。

- 中断，定时器是基于时间的，而外设则是事件触发的。优先级0最高。系统定时器SysTick是内核外设，24位递减，ms计时作为操作系统心跳；通用定时器是STM32片上外设，挂在APB总线，功能更多。
- 原则：**中断只负责计时、修改状态标志；不做复杂动作（不点亮 LED、不跑流水灯循环）；流水灯、传感器全部交给主循环前台执行**。

-  EXTI外部事件控制器，边沿检测器（有表和引脚对应，中断优先级分为抢占优先级和响应优先级）。NVIC管理调度中断。
-  EXTI 边沿检测是同一个，硬件有两个独立分支：
   -  分支 A：**中断通路（IMR）** → 产生中断请求，进 NVIC，触发中断
   -  分支 B：**事件通路（EMR）** → 输出事件脉冲，给 ADC/DMA/TIM/WFE，**不进 NVIC**
-  中断服务函数（例如，定时器函数），是 CPU 中断向量表对应的地址；HAL 库回调函数，是**软件调用**的普通函数属于**库函数**。下面区分3个函数：

1. 按键下降沿 → EXTI 硬件检测到边沿，置 PR 挂起标志 → 向 NVIC 发中断请求

2. CPU 放下主循环，跳转到 `EXTI0_IRQHandler()`**真正的中断服务函数（IRQ 入口函数）**

3. 执行 。`HAL_GPIO_EXTI_IRQHandler(KEY1_Pin)`**中断通用处理函数（库内部函数）**

   -  读取 PR 标志，确认中断有效

   -  **清除 PR 标志（非常关键）**
   -  调用 `HAL_GPIO_EXTI_Callback(KEY1_Pin)`**弱定义回调函数（给用户写业务的钩子函数）**

4. 跑到你自己重写的 `HAL_GPIO_EXTI_Callback`，你在这里设置 `key_flag = 1;`

5. 回调执行完，一层层 return，CPU 回到被打断的主循环继续跑
